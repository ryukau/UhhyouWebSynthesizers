Integer Sample BPMs

Glossary
  • fs : Audio sampling rate in Hz.
  • BPM : Beats per minute.
  • N : Number of audio samples per beat.
Explanation

This table lists BPM values that result in an integer number of audio samples per beat (N) and are exactly representable in IEEE 754 double-precision floating-point numbers.

The samples per beat is given by: N = 60 × fs / BPM.

To guarantee exact representability, N is factored into d × 2k, where d is an odd divisor of 60 × fs.
