Integer Sample BPMs

Glossary
  • fs : Sampling rate in Hz.
  • BPM : Beats per minute.
  • N : Samples per beat.
Explanation

This table lists BPM values that result in an integer number of audio samples per beat (N) and are exactly representable in 64-bit float.

The samples per beat is given by: N = 60 × fs / BPM.

To guarantee exact representability, N is factored into d × 2k, where d is an odd divisor of 60 × fs.
